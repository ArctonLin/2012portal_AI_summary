[Relevant content] [reported] Cobra states that the basic control network of the awakening group is on the plasma plane, involving the Archon network on non-physical planes, which controls the incarnation process. [reported] Cobra identifies the plan of the Archons as creating an A.I. singularity where immortal physical bodies are tied to a machine network, allowing a high cloud computerized network to control minds.

"One thing that we have to be aware of, there is the so-called A.I prophets that want to create a singularity... and this is exactly what the plan of the Archons is, but it will not, of course not be successful."
